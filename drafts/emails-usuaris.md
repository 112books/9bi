**Assumpte:** Accés al gestor de continguts de 9 Barris Imatge

Hola, [Nom]:

Ja hem posat en marxa el Gestor de continguts del web de 9 Barris Imatge. Per publicar articles, has de completar aquests passos:

1. Crea el teu compte de GitHub a https://github.com/signup, si encara no en tens un.
2. Accepta la invitació de col·laborador que t'enviem al repositori del web. Si no l'has rebut, revisa la carpeta de correu no desitjat o la secció **Notifications** de GitHub.
3. Crea un token personal a **GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)**. Tria **Generate new token**, marca l'àmbit **repo** i guarda el token, Només es mostra una vegada.
4. Entra a https://9barrisimatge.org/admin/, fes clic a **Sign In with Token** i enganxa el teu token.

La guia completa està a https://9barrisimatge.org/guia/.

Recorda que el token dóna accés d'escriptura al repositori. No l'enviis a ningú ni el comparteixis. Si creus que algú el pot tenir, revoca'l i crea'n un de nou.

Si ets una persona ativa del col·lectiu, recorda seleccionar el teu nom en el camp **Autor** quan publiquis un article. Si necessites ajuda, respon aquest correu.
